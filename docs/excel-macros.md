# Excel一覧テンプレート

[概要に戻る](../README.md)。`tools/excel-macros/` に次の2つのテンプレートを同梱しています。

| テンプレート | 用途 |
| --- | --- |
| `FileInventory.xltm` | フォルダ内のファイル一覧（子フォルダも含む） |
| `SheetInventory.xltm` | 選択したExcelファイル、またはフォルダ内のExcelファイルのシート一覧 |

## 共通の起動・終了・保存

起動メニューの「Excel: …xltm」を選ぶか、テンプレートをダブルクリックします。メニューはWindowsの `New` 操作でテンプレートから実行用コピーを作成します。Excelでマクロが有効な場合に起動時の選択画面が開きます。起動時処理が動かなかった場合は［設定］シートのボタンから実行できます。

結果は別の新しいブックに出力し、処理完了後は実行用ブックを保存せず自動で閉じます。キャンセル時も実行用ブックを閉じます。結果ブックはそのまま残るので、必要なものを名前を付けて保存してください。処理中に入力した条件・探索先・一覧はテンプレートに書き戻しません。

実行用ブックには、マクロが有効な場合の保存・名前を付けて保存を取り消す処理も入れています。結果ブックの保存には影響しません。テンプレートそのものを編集する場合はVBAソースと生成スクリプトを利用してください。

## 進捗率

Excel下部のステータスバーに2段階で表示します。

1. **対象を収集中**：フォルダを探索して対象の総数を確定します。この段階は件数が未確定のため、探索中のパスを表示します。
2. **一覧作成中 42% (42/100)**：対象が確定した後、処理済み件数を総数で割った割合を表示します。ファイル一覧では条件に一致したファイル数、シート一覧では対象ブック数を分母にします。読み取りに失敗した対象も処理済み件数に含めます。

［実行情報］には処理件数と進捗率を残します。完了時は100%、処理中断時はその時点の割合です。ステータスバーの表示状態やExcelのイベント設定などは処理後に元へ戻します。

## ファイル一覧

`FileInventory.xltm` を起動するとフォルダ選択画面が開き、次の正規表現を順に入力できます。［設定］B4～B7を初期値とし、空欄は全件、大文字小文字は区別しません。

| 条件 | 対象と例 |
| --- | --- |
| 拡張子 | ドットなし。`^csv$` はCSVのみ、`^$` は拡張子なし |
| ファイル名 | 拡張子を含む名前。`^売上.*` など |
| 相対フォルダ | ルートは `.`、子は `年度\請求` のようなパス。`請求` はその文字を含むパス |
| 除外フォルダ | 一致したフォルダは配下も探索しない。例：`node_modules` |

次の例はそのまま入力欄へコピーできます。

```text
拡張子:       ^(xlsx|xlsm|csv)$
相対フォルダ: (^|\\)請求(\\|$)
除外フォルダ: (^|\\)(\.git|node_modules)(\\|$)
```

条件はANDで組み合わせます。相対フォルダ条件に一致しない親の下も探索するため、深い位置にある対象フォルダも見つかります。正規表現は `VBScript.RegExp` の構文です。不正な式は探索開始前に表示します。

［ファイル一覧］には名前・拡張子・相対フォルダ・相対パス・フルパス・サイズ・更新日時を出力します。ファイル名が `=` などで始まっても数式にはしません。

## シート一覧

`SheetInventory.xltm` を起動すると対象を選ぶ画面が開きます。

- **1：フォルダ**：フォルダ選択後、子フォルダも含めてExcelファイルを探索します。
- **2：Excelファイル**：ファイルを1つ選択します。

その後、ブック名・相対フォルダ・除外フォルダ・シート名の正規表現を入力できます。条件はANDで、空欄は全件です。単一ファイルを選んだ場合の相対フォルダは `.` として扱います。

対象形式は `.xlsx`・`.xlsm`・`.xlsb`・`.xls`・`.xltx`・`.xltm`・`.xlt`・`.xlam`・`.xla` です。［シート一覧］にはブック名・相対パス・フルパス・シート順・シート名・種類・表示状態・相対フォルダを出力します。非表示・VeryHiddenのシートと、グラフシートも含めます。セルの内容は取得しません。

対象ブックは読み取り専用で、VBAと起動イベントを無効にし、外部参照リンクを更新せず開きます。マクロ自身が開いたブックだけを保存せず閉じます。既に同じブックが開いている場合は、その現在のシート構成を読み取り、保存・終了しません。Excel 4.0マクロの確認はExcel側の設定に従います。

パスワード保護・破損・アクセス不可などで取得できなかったブックは［探索エラー］に記録し、残りを処理します。失敗がある場合も［実行情報］の件数を確認してください。

## 探索と出力の制約

子フォルダを探索しますが、Junction・SymbolicLinkなどの再解析ポイントはたどりません。途中のアクセスエラーは記録して継続します。Esc / Ctrl+Breakで中断した場合やExcelの行数上限に達した場合は、取得済みの結果と中断理由を残します。対象収集中に中断した場合は、まだ一覧行は作成されていません。

一覧は実行中のファイルシステムを読み取るもので、スナップショットではありません。ブックを読み取れなかった場合や対象が途中で消えた場合は、エラー欄も確認してください。

## ソースと再生成

VBAソースは `lib/FileInventory.bas`・`lib/SheetInventory.bas`、共通処理は `lib/InventoryCommon.bas`、起動・保存防止イベントは `lib/ThisWorkbook.cls` です。

```powershell
# 両方を生成（ExcelとVBAプロジェクトへのプログラムアクセスが必要）
./tools/excel-macros/lib/Build-InventoryTemplates.ps1 -Force

# 一方だけを生成
./tools/excel-macros/lib/Build-InventoryTemplates.ps1 -Kind Sheet -Force
```

生成スクリプトは専用Excelを非表示で使用し、永続的なセキュリティ設定や信頼済みフォルダを変更しません。配布テンプレートの作成者メタデータは `win-tools` とし、ローカル保存パスを除去します。

```powershell
# Excelを起動しないパッケージ・メタデータ検証
Invoke-Pester ./tests/excel-macros

# 実際のExcelで機能・進捗・保存防止・自動終了を検証
./tests/excel-macros/Test-FileInventoryExcel.ps1
./tests/excel-macros/Test-SheetInventoryExcel.ps1
```

旧 `FileInventory.xlsm` は `FileInventory.xltm` に置き換えました。旧ブックへのショートカットは新しいテンプレートへ変更してください。旧 `Build-FileInventoryWorkbook.ps1` は `Build-InventoryTemplates.ps1` に統合しています。

## 配置と起動

次のようにマクロのファイルを追加します。用途別のサブフォルダも利用できます。

```text
tools/excel-macros/
├─ .gitignore
├─ FileInventory.xltm
├─ SheetInventory.xltm
├─ lib/                 # 同梱マクロのソースと生成スクリプト
├─ 集計ツール.xlsm
└─ 帳票/
   └─ 帳票作成.xlsm
```

対応する[Excelの形式](https://support.microsoft.com/en-us/excel/file-formats-that-are-supported-in-excel)は `.xlsm`・`.xlsb`・`.xlam`・`.xltm` です。拡張子の大文字小文字は区別しません。`.bas`・`.cls`・`.frm` はVBAソースとして配置できますが、単体で開いて実行するブックではないためメニューには表示しません。

`Start-WinTools.ps1` または `Start-WinTools.bat` を起動すると、「Excel: 帳票\帳票作成.xlsm」のように相対パスで一覧へ追加されます。メニューを再表示するたびに一覧を作り直すので、追加時の登録作業は不要です。

選択するとWindowsのファイル関連付けで開きます。対応するExcelと関連付けが必要です。個別のVBAプロシージャ名は指定せず、開いたブックのボタンや操作画面から利用する形です。ブックの起動時処理やマクロの有効・無効はExcel側の設定に従います。

## ツールと作業データの区別

Gitで管理するツール本体は `tools/excel-macros/` に置きます。このフォルダ内に限り、対応するマクロ形式を `.gitignore` の除外から戻しています。通常の業務ブックを置く他の場所では、Excelファイルの除外を継続します。

入力データや生成した帳票はリポジトリ外、またはマクロ用フォルダ内の `data/`・`input/`・`output/`・`local/` に保存します。これらのフォルダはGit管理とメニューの検索から除外します。`~$` で始まるExcelのロックファイル、`*.local.*`・`*.secrets.*`・`*.credentials.*` も対象外です。

隠し項目、名前が `.` で始まる項目、子のJunction・SymbolicLinkも検索しません。Gitに追加するツールブックには、個人情報・実際の業務データ・接続用の秘密情報が入っていないことを確認してください。入力用の `.xlsx` はこのフォルダ内でもGitの除外対象です。
