# Excelマクロツール

[概要に戻る](../README.md)。マクロツールの配置先は `tools/excel-macros/` です。ファイル一覧を作る `FileInventory.xlsm` を同梱しています。

## ファイル一覧マクロ

起動メニューの「Excel: FileInventory.xlsm」を選ぶか、同ブックを開きます。マクロが有効な環境では、起動時にフォルダ選択画面が開きます。Excelでマクロが無効な場合は、通常の運用ルールに従って扱ってください。起動時処理が動かなかった場合も、［設定］シートの「フォルダを選んで一覧を作成」ボタンから実行できます。

フォルダを選ぶと、次の条件を順に入力できます。［設定］B4～B7の値を初期値として使い、空欄は全件、大文字小文字は区別しません。フォルダ選択・条件入力でキャンセルした場合は探索しません。

| 条件 | 対象と例 |
| --- | --- |
| 拡張子 | ドットを含まない拡張子。`^csv$` はCSVのみ、`^$` は拡張子なし |
| ファイル名 | 拡張子を含む名前。`^売上.*` など |
| 相対フォルダ | 選択したルートを `.`、子を `年度\請求` のように扱う。`請求` はパスに「請求」を含むもの |
| 除外フォルダ | 一致したフォルダは配下の探索も省略。例：`node_modules` |

次の例は、そのまま入力欄にコピーできます。

```text
拡張子:       ^(xlsx|xlsm|csv)$
相対フォルダ: (^|\\)請求(\\|$)
除外フォルダ: (^|\\)(\.git|node_modules)(\\|$)
```

条件はANDで組み合わせます。相対フォルダに一致しない親の下も探索するため、深い場所にある対象フォルダも見つかります。正規表現はWindowsの `VBScript.RegExp` を使うため、.NETの正規表現とは構文が異なり、後読みなどは使えません。不正な式は探索開始前に表示します。

結果は別の新しいブックに作成します。［ファイル一覧］には名前・拡張子・相対フォルダ・相対パス・フルパス・サイズ・更新日時を、［探索エラー］には取得できなかった場所を記録し、［実行情報］には条件・件数・除外やリンクの数を残します。ダイアログで入力した条件・選択フォルダ・一覧は、ツール本体に書き戻しません。必要な結果だけ名前を付けて保存してください。

子フォルダも探索しますが、Junction・SymbolicLinkなどの再解析ポイントはたどりません。エラーになった場所は記録して探索を継続します。Esc / Ctrl+Breakで中断した場合やExcelの行数上限に達した場合は、取得済みの結果と中断理由を残します。ファイル名は文字列として出力し、`=` などで始まる名前をExcelの数式として扱いません。

### ソースと再生成

VBAソースは `lib/FileInventory.bas`、起動イベントは `lib/ThisWorkbook.cls` です。UTF-8で管理し、生成スクリプトがUnicodeとしてExcelへ渡します。

```powershell
./tools/excel-macros/lib/Build-FileInventoryWorkbook.ps1 -Force
```

再生成にはWindowsのExcelと、VBAプロジェクトへのプログラムアクセスが必要です。生成スクリプトは非表示の専用Excelを使用し、永続的なセキュリティ設定や信頼済みフォルダを自動変更しません。配布ブックの作者メタデータを `win-tools` にし、ローカル保存パスを除去します。通常の利用に再生成は不要です。

```powershell
# パッケージ・メタデータ・起動メニューのテスト（Excelを起動しない）
Invoke-Pester ./tests/excel-macros

# 実際のExcelで再帰探索・正規表現・1,000件超の出力を検証
./tests/excel-macros/Test-FileInventoryExcel.ps1
```

## 配置と起動

次のようにマクロのファイルを追加します。用途別のサブフォルダも利用できます。

```text
tools/excel-macros/
├─ .gitignore
├─ FileInventory.xlsm
├─ lib/                 # 同梱マクロのソースと生成スクリプト
├─ 集計ツール.xlsm
└─ 帳票/
   └─ 帳票作成.xlsm
```

対応する[Excelの形式](https://support.microsoft.com/en-us/excel/file-formats-that-are-supported-in-excel)は `.xlsm`・`.xlsb`・`.xlam`・`.xltm` です。拡張子の大文字小文字は区別しません。`.bas`・`.cls`・`.frm` はVBAソースとして配置できますが、単体で開いて実行するブックではないためメニューには表示しません。

`Start-WinTools.ps1` または `Start-WinTools.bat` を起動すると、「Excel: 帳票\帳票作成.xlsm」のように相対パスで一覧へ追加されます。メニューを再表示するたびに一覧を作り直すので、追加時の登録作業は不要です。

選択するとWindowsのファイル関連付けで開きます。対応するExcelと関連付けが必要です。個別のVBAプロシージャ名は指定せず、開いたブックのボタンや操作画面から利用する形です。ブックの起動時処理やマクロの有効・無効はExcel側の設定に従います。

## ツールと作業データの区別

Gitで管理するツール本体は `tools/excel-macros/` に置きます。このフォルダ内に限り、対応するマクロ形式を `.gitignore` の除外から戻しています。通常の業務ブックを置く他の場所では、Excelファイルの除外を継続します。

入力データや生成した帳票はリポジトリ外、またはマクロ用フォルダ内の `data/`・`input/`・`output/`・`local/` に保存します。これらのフォルダはGit管理とメニューの検索から除外します。`~$` で始まるExcelのロックファイル、`*.local.*`・`*.secrets.*`・`*.credentials.*` も対象外です。

隠し項目、名前が `.` で始まる項目、子のJunction・SymbolicLinkも検索しません。Gitに追加するツールブックには、個人情報・実際の業務データ・接続用の秘密情報が入っていないことを確認してください。入力用の `.xlsx` はこのフォルダ内でもGitの除外対象です。
