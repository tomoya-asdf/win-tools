# 起動メニュー

[概要に戻る](../README.md)。リポジトリのルートで次のコマンドを実行するか、`Start-WinTools.bat` をダブルクリックします。別のカレントディレクトリから起動しても利用できます。

```powershell
./Start-WinTools.ps1

# 起動せずに現在の項目を確認
./Start-WinTools.ps1 -List | Format-Table Number, Name
```

## 選べるツール

| 番号 | 機能 | 入力するもの |
| --- | --- | --- |
| 1 | フォルダ比較 | 左右のフォルダ、SHA-256比較の有無 |
| 2 | 業務イベントログ | カテゴリ（空欄はErrors） |
| 3 | フォルダ操作履歴 | 既定条件で取得。管理者として起動する必要あり |
| 4 | 一時保存へコピー | コピー元、保存先（空欄は既定の保存先） |
| 5 | 一時保存のコピー品を削除 | 保存先。削除前の確認は既存ツール側で行う |
| 6 | 一時保存の自動リネーム監視 | 監視先。別プロセスでトレイ常駐 |
| 7以降 | 追加したExcelマクロ | 一覧から番号を選択 |
| 0 | 終了 | ― |

パスは引用符付きでも入力できます。フォルダ比較は差分・比較できなかった項目を表示します。詳細な期間・件数の指定やCSVへの保存には、それぞれのPowerShellを直接利用してください。

監視を起動するとメニューへ戻れます。監視はトレイアイコンの `Exit` から終了します。メニューの終了とは独立して動作するため、同じ保存先で監視を重複起動しないでください。

実行エラーはメニューに表示し、Enterで選択画面へ戻ります。管理者権限が必要な項目を使う場合は、PowerShellを管理者として起動してからこのメニューを実行してください。

## Excelマクロの追加

`tools/excel-macros/` 内の対応ファイルをサブフォルダも含めて自動検出します。メニューを再表示するたびに一覧を更新するので、起動中に追加・削除したファイルも反映されます。番号は表示されている一覧を確認して選んでください。

追加方法、対象拡張子、作業データの配置については[Excelマクロツール](excel-macros.md)を参照してください。

組み込みツールの一覧と入力処理は `tools/launcher/lib/WinToolsMenu.psm1` にまとめています。新しいPowerShellツールをメニューへ追加する場合は、同モジュールの定義と起動処理を更新します。Excelマクロブックの追加ではコードの変更は不要です。
