# 起動メニュー

[README](../README.md) / [セットアップ](setup.md)

`Start-WinTools.bat`、`./Start-WinTools.ps1`、登録済みの **Ctrl + Alt + W** で起動します。

```powershell
# メニューを開かず、現在のトップレベル項目を取得
./Start-WinTools.ps1 -List | Format-Table Number, Name
```

## 操作

番号で選択します。`0`はメインメニューで終了、子メニューで一つ上へ戻る操作です。メニュー再表示時と機能の入力前に画面をクリアし、結果・エラーはEnterを押すまで表示します。`-List`は画面をクリアしません。

組み込み機能はフォルダ比較、Windowsログ、一時保存、監視、実行履歴です。追加アプリとExcelマクロも表示します。番号はその時点の一覧で確認してください。管理者用の機能は、PowerShellを管理者として起動して利用します。

## 自分のアプリを追加

リポジトリ直下の`apps/`へファイルを置きます。フォルダがなければ対話起動時に作成します。`-List`は作成しません。

```text
apps/
├─ ブラウザ.lnk
├─ アプリ.exe
└─ 仕事/
   ├─ 社内サイト.url
   └─ 資料/
      └─ 手順書.pdf
```

- 直下のファイル・フォルダはメインメニューに表示します。
- フォルダを選ぶと直下の一覧へ移動し、さらに階層をたどれます。
- ファイルはWindowsの既定の動作で開きます。ショートカットの引数もそのまま利用します。
- 追加・削除・名前変更はメニューの再表示時に反映します。登録処理は不要です。
- 空フォルダも選べます。隠し項目・ドット始まりの項目・Junction・SymbolicLinkは表示しません。リンクには`.lnk`を使ってください。

`apps/`は配下を含めてGit管理から除外します。ソフトを移動せず使う場合や、ポータブルアプリの補助ファイルをメニューに出したくない場合は、起動用のショートカットだけを置いてください。既定アプリがないファイルや削除済みの項目は、起動エラーを表示します。

## Excelマクロ

共有・バージョン管理するマクロは`tools/excel-macros/`に配置します。対応ブックを再帰的に検出し、一覧へ追加します。`.xltm`はテンプレートから新規作成して開きます。対応形式とデータの配置は[Excelマクロ](excel-macros.md)を参照してください。

## 実行履歴

メニューの「Win Toolsの実行履歴」で直近50件を表示します。保存先は`%LOCALAPPDATA%\WinTools\History\yyyy-MM.history.jsonl`です。

開始・終了日時、機能名、ツールのパス、結果、所要時間（入力待ちを含む）、エラーを記録します。画面出力や入力条件は保存しません。エラーには対象パスが含まれる場合があります。フォルダ間の移動は履歴に残しません。

| Status | 意味 |
| --- | --- |
| `Succeeded` | コマンドがエラーを送出せず終了。個別の探索エラー・警告は結果で確認 |
| `Cancelled` | フォルダ比較・一時保存コピーの入力を空欄にして戻った |
| `Failed` | 実行・起動に失敗 |
| `Launched` | 追加アプリ・Excel・監視の起動要求を受け付けた。起動後の処理は追跡しない |

```powershell
./tools/launcher/Get-WinToolsHistory.ps1 |
  Format-Table StartTime, Name, Status, DurationMs, Error -Wrap

./tools/launcher/Get-WinToolsHistory.ps1 -Last 200 | Where-Object Status -eq Failed
```

機能の直接実行・ランチャーの強制終了は記録対象外です。履歴表示も実行後に記録します。保存失敗時は警告を表示し、履歴は自動削除しません。
